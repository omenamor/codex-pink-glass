# Codex Custom Themes for Windows

Пять тем и меню кастомизации для Codex на Windows: **Sakura, Lavender, Moonlight, Peach и Mint**. Ранее приложение называлось Pink Glass. Технический идентификатор `pink-glass` сохранён, поэтому установленные профили и команды обновления совместимы.

## Установка и включение

В новой задаче Codex напишите: **«Установи и включи Codex Custom Themes for Windows»**. Плагин проверит файлы, установит локальный запускатель и создаст одноимённый ярлык. Если Codex уже открыт без подключения темы, завершите задачи, полностью закройте приложение и запустите ярлык. Приложение не закрывается автоматически.

Также доступен обычный установщик Windows в [Releases](https://github.com/omenamor/codex-pink-glass/releases/latest).

## Меню «Тема»

Нажмите **«✿ Тема»** в правом верхнем углу или попросите Codex открыть меню настройки темы. Изменения видны сразу; нажмите **«Сохранить»**, чтобы сохранить их. При переключении темы текущие настройки также сохраняются.

| Раздел | Что можно изменить |
| --- | --- |
| Стекло и прозрачность | Прозрачность поля ввода, размытие стекла и прозрачность левого меню. |
| Цвета | Фон, боковую панель, поле ввода и меню, текст, кнопки, границы и свои сообщения — через палитру или HEX. |
| Фон | Видимость картинки, затемнение, приглушение фона слева, цветную тонировку и её силу. |
| Размеры и тени | Скругление панелей и кнопок, мягкую тень и размер своих иконок. |
| Свои изображения | Свой фон, логотип и иконки отправки и остановки. PNG, JPG или WebP до 25 МБ; большие картинки уменьшаются автоматически. |

**«Отменить правки»** возвращает последнее сохранённое состояние. **«Вернуть цвета темы»** сбрасывает только цвета, **«Сбросить настройки темы»** — текущую тему целиком. Остальные профили сохраняются.

**«Экспорт»** сохраняет текущую тему в JSON вместе со своими изображениями. **«Импорт»** загружает такой файл как предпросмотр в текущую тему; после проверки нажмите **«Сохранить»**. Файл экспорта может содержать ваши фотографии — перед передачей другим людям проверьте его содержимое.

Прозрачность стекла 0% означает непрозрачную поверхность; большее значение показывает больше фона. Подложки текста ответов сохраняют отдельную защиту читаемости. В Moonlight текст бокового меню остаётся белым. Ползунок приглушения слева: 0% — без дополнительного приглушения, 100% — ровный фон без рисунка. Системное уменьшение прозрачности имеет приоритет над прозрачностью поверхностей.

## Управление через Codex

- «Включи Moonlight».
- «Открой меню настройки темы».
- «Проверь, включено ли оформление».
- «Отключи оформление».

## Как работает и удаляется

Неофициальное оформление для Windows x64. Подключается к Codex локально на `127.0.0.1:9337`; файлы Codex не переписываются. Node.js входит в пакет, ключи API не нужны. Обновления Codex могут потребовать адаптации оформления.

Чтобы удалить плагин, сначала попросите отключить оформление, затем удалите плагин в Codex. Установку через EXE можно удалить в параметрах Windows. Обычный полный перезапуск Codex также отключает мод. Сохранённые настройки тем остаются в профиле Codex.
