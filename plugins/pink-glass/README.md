# Pink Glass для Codex · Windows

Пять встроенных тем: Sakura, Lavender, Moonlight, Peach и Mint. У каждой свои фон, палитра и сохранённые настройки. В редакторе доступны прозрачность, тонировка, фон, цвета, размеры и собственные изображения.

## Использование

Установите плагин через его карточку. В новой задаче напишите **«Установи и включи Pink Glass»**. Плагин проверит файлы и подготовит локальный запускатель. Если Codex открыт без отладочного подключения, завершите задачи, полностью закройте Codex и откройте `Codex Pink.vbs` по пути, который выдаст плагин. Приложение автоматически не закрывается.

После запуска: **«Включи Moonlight»**, **«Открой настройки Pink Glass»**, **«Проверь Pink Glass»**, **«Отключи Pink Glass»**. Выбор темы сохраняется; настройки других профилей сохраняются отдельно.

## Как это работает

Это неофициальная надстройка, а не встроенный API оформления. Skill управляет локальным модом. Мод добавляет CSS и редактор в окно Codex через проверенное локальное отладочное подключение на порту 9337. Файлы установленного Codex не переписываются. Node и все пять тем включены в пакет. Ключи аккаунта и внешние сервисы не нужны.

Плагин рассчитан на Windows и пакет OpenAI.Codex с исполняемым файлом app/ChatGPT.exe. В комплекте Node для Windows x64. Обновления Codex могут менять структуру интерфейса и требовать обновления мода.

## Удаление и настройки

Сначала попросите **«Отключи Pink Glass»**, затем удалите плагин в меню Codex. Удаление карточки плагина само по себе не останавливает уже запущенный внешний коннектор. Обычный полный перезапуск Codex также отключает мод и отладочный порт.

Runtime сохраняется отдельно в `%LOCALAPPDATA%\PinkGlassPlugin\<версия>-<хеш пакета>`, чтобы обновление плагина не меняло файлы запущенного процесса. Установка создаёт ярлык **Codex Pink Glass** на рабочем столе и выводит фактический путь запуска. В версии Codex из Microsoft Store Windows может перенаправлять файлы в служебную папку LocalCache; установщик учитывает это автоматически. Используйте созданный ярлык или напечатанный путь, не составляйте путь вручную. Настройки остаются в локальном профиле Codex. После обновления работающий мод продолжает работать; новый ярлык применяется при следующем обычном перезапуске. Старые файлы и настройки не удаляются. Уже работающий мод из другой папки нужно сначала отключить его прежним запускателем, если требуется переключиться без перезапуска.

## Распространение

Каталог содержит `.codex-plugin/plugin.json`, skill и проверяемый пакет мода. Его можно передавать как исходный каталог/ZIP плагина. Локальная установка в личный каталог плагинов не означает публикацию в официальном каталоге OpenAI. Для публикации в стороннем marketplace потребуется его запись, а для официального каталога — отдельная процедура рассмотрения.
